# 坎友会 Guardian Guild · GTCG

《坎特伯雷公主与骑士》同人卡牌游戏 GTCG —— 卡牌图鉴、卡组构筑、线上试玩、坎友圈、规则书。

纯静态站点，**双击 `index.html` 即可用浏览器打开**，无需安装、无需构建、可离线运行。

## 目录结构

```
index.html          单页应用：首页 / 卡牌中心 / 线上试玩 / 坎友圈 / 规则书
css/style.css       全站样式（含对局台布局与战斗动效）
js/cards-data.js    第一弹 24 张卡牌数据 + 关键词定义
js/main.js          页面路由、卡牌图鉴筛选、卡牌详情弹窗
js/deck.js          卡组构筑器（40 张 / 同名最多 4 张）+ 对战卡组选择
js/game.js          线上试玩：规则引擎 + 界面 + AI
js/forum.js         坎友圈（依赖 WorkBuddy 云 SDK，离线时该页不可用）
js/cloud-config.js  云服务公共配置
tests/              自动化测试（真实浏览器驱动，见 tests/README.md）
```

## 规则实现

线上试玩按《GTCG 规则书 0.1》（见站内「规则书」页）实现：

- **卡组**：40 张、同名最多 4 张；冠军之剑不入卡组，开局即在双方 EX ZONE。
- **对局准备**：掷骰定先手 → 双方各从手牌选 1 张填入能量区（活跃入区）→ 先手第一回合不抽牌。
- **回合**：抽牌 → 填能 → 主要 → 战斗，**不可回退**；能量区每回合开始全部恢复。
- **费用**：单属性卡需至少 1 张同属性能量；每回合最多填 1 张；共鸣值上限 12。
- **战斗**：默认只能攻击疲劳角色，[突袭] 可打活跃；战力比大小，赢家本回合减去输家战力，
  输家被击破，平点同归于尽；战力减到 0 也算击破；被击破的角色连同装备进废弃区。
- **共鸣**：专属武器装到专属角色身上即触发 [共鸣时]，共鸣状态当回合即可攻击。
- **胜利**：冠军之剑命中对方本体直接获胜；必须抽牌而牌库已空则败。

### 代码结构

`js/game.js` 的卡牌效果用**登记表**驱动，而不是一长串 `if (card.id === ...)`：

| 表 | 时点 |
|---|---|
| `ON_ENTER` | 角色 [登场时] |
| `ON_EVENT` | 事件卡结算 |
| `ON_ATTACK` | [攻击时]（含装备卡自身效果） |
| `ON_GUARD` | [守护时] |
| `ON_RESONATE` | [共鸣时] |
| `ON_EQUIP` | 装备武器时的静态加成 |
| `AI_WANTS` | AI 对事件卡的出牌意愿 |

新增卡牌只需在对应表里加一条记录，不必改控制流。处理器统一签名 `handler(ctx)`，
通过 `ctx.api` 调用规则原语（抽牌、击破、选目标…）。

### 操作方式

**出牌一律靠拖拽**，单击手牌只给提示（告诉你这张牌现在能拖到哪、为什么不能拖），
双击放大看卡图。这样避免误触，也让「为什么打不出去」有明确反馈。

| 想做什么 | 拖到哪 |
|---|---|
| 填能量 | 下方**费用区**（每回合限 1 张） |
| 出角色 / 事件 | **自己半场** |
| 装装备 | **具体角色身上**（类型 / 专属不匹配会被拒） |
| 攻击角色 | 把角色拖到**敌方角色**上 |
| 攻击本体 | 把角色拖到**对面半场** |

也可以点自己场上的角色，从弹出的目标菜单里选。

**[守护] 是锁定目标**：对方场上有活跃的守护角色时，攻击方只能先攻击它 ——
既不能打本体，也不能打其它角色；守护者疲劳后锁定解除。拖拽时对面半场会显示 🔒 提示。

## 测试

```bash
node tests/run.mjs        # 125 条断言：规则 / 界面 / 交互 / 组卡器 / 装备
node tests/measure.mjs    # 量区域矩形，检测区块重叠

node tests/deck.mjs       # 组卡器 + 对战卡组选择器 + 装备安装
node tests/soak.mjs 20    # 多回合对局压测（抓卡死 / busy 不复位 / 弹窗残留）
node tests/shot.mjs       # 摆中局场面并截图
```

测试用 CDP 驱动本机 Edge/Chrome 打开**真实的 index.html**，不装任何 npm 包。
